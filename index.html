Kenapa Berbasis NusantaraProject?

NusantaraProject adalah custom ROM Indonesia yang bersih, stabil, dan mudah dimodifikasi

🇮🇩 Buatan Indonesia

Dikembangkan oleh developer Indonesia dengan pemahaman mendalam tentang kebutuhan pengguna Indonesia.

Bebas bloatware dan iklan. Nikmati pengalaman Android murni tanpa gangguan.

📥 Instalasi

Langkah-Langkah Setup

Ikuti langkah-langkah berikut untuk menyiapkan environment build

1

Clone Repository

Clone repository panduan ini ke komputer Anda

git clone https://github.com/antono4/Custom-Android-OS-from-NusantaraROM.git cd Custom-Android-OS-from-NusantaraROM
2

Fork NusantaraProject

Fork repository yang diperlukan di GitHub

# Buka browser ke: https://github.com/NusantaraProject-ROM/ # Fork repository berikut: ✓ android_manifest ✓ android_vendor_nusantara ✓ android_packages_apps_NusantaraWings ✓ android_packages_apps_Settings ✓ android_frameworks_base
3

Setup Build Environment

Jalankan script setup untuk install semua dependencies

chmod +x setup_custom_rom.sh ./setup_custom_rom.sh
4

Buat Direktori Kerja

Buat direktori untuk source code ROM

mkdir -p ~/custom-rom && cd ~/custom-rom
🔧 Build

Proses Build ROM

Ikuti alur berikut untuk membangun custom ROM Anda

📊 Build Flow Diagram

Download Source

Output IMG
1

Inisialisasi Repo

Inisialisasi repo dengan manifest fork Anda

# Ganti USERNAME dengan username GitHub Anda repo init -u https://github.com/USERNAME/android_manifest -b 12
2

Sinkronisasi Source

Download semua source dari repository (bisa memakan waktu 2-6 jam)

repo sync -c --force-sync --no-tags --no-clone-bundle -j$(nproc --all)
3

Setup Environment

Load environment variables untuk build

source build/envsetup.sh
4

Pilih Device

Pilih perangkat target yang akan di-build

lunch # Pilih device, contoh: lunch nad_redfin-userdebug
5

Build ROM

Mulai proses build (bisa memakan waktu 3-8 jam)

make nad -j$(nproc --all) # Atau lebih spesifik: make systemimage vendorimage -j$(nproc --all)

❓ FAQ

Pertanyaan Umum

Berapa lama untuk build ROM pertama kali?
Tergantung hardware, biasanya 3-8 jam untuk build pertama. Build berikutnya bisa 30 menit - 1 jam dengan ccache.
Apakah saya bisa build tanpa Linux?
Bisa dengan WSL2 di Windows 11 atau menggunakan virtual machine. Namun, build langsung di Linux lebih stabil dan disarankan.
ROM apa saja yang support?
Semua device yang memiliki device tree di NusantaraProject. Untuk referensi, cek daftar device di XDA NusantaraROM.
Bagaimana cara berkontribusi?
1. Fork repository NusantaraProject
2. Buat branch baru untuk fitur/fix
3. Commit perubahan Anda
4. Submit pull request
Apakah aman untuk daily use?
Custom ROM bisa digunakan untuk daily use jika di-build dengan benar. Namun, selalu backup data sebelum flash ke perangkat.
